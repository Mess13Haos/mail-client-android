# Отчёт QA — MailClient

## Краткий план проверки
1. Проверить среду и доступность устройства/ADB/test-аккаунтов.
2. Выполнить локальные автоматические проверки, которые можно запустить в текущем окружении.
3. Для каждой проверки T1–T8 зафиксировать статус PASS/FAIL и приложить фрагменты логов, если они доступны.

## Состояние среды
- Тестовый Android-устройства Samsung SM-J320F, API 25, Android 7.1.2 в этом окружении недоступен.
- Команда ADB не установлена в контейнере: `adb: command not found`.
- Тестовые IMAP-аккаунты (минимум 2, изолированные) не созданы.
- По этим причинам реальные кейсы T1–T8 на железе не могут быть выполнены в текущем сеансе.

## Автоматическая проверка, выполнимая в текущем окружении
- Команда: `./gradlew app:testDebugUnitTest --quiet`
- Результат: PASS (exit code 0)
- Вывод: `BUILD SUCCESSFUL` для unit-test task в текущем окружении.

Фрагмент логов:
```text
$ ./gradlew app:testDebugUnitTest --quiet
BUILD SUCCESSFUL in 2s
```
